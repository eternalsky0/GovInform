## О проекте

**ГорИнформ** - это инновационная платформа для информирования населения о коммунальных происшествиях в режиме реального времени. Проект разработан для улучшения взаимодействия между ресурсоснабжающими организациями (РСО) и жителями города.

### 🎯 Основные возможности

- Мгновенные уведомления об авариях и плановых работах
- Интерактивная карта происшествий
- Прямая связь с диспетчерскими службами
- ИИ-помощник для ответов на частые вопросы
- Отслеживание статуса выполнения работ
- Push-уведомления о важных событиях

### 🔍 Преимущества

- **Для жителей**
  - Оперативное получение информации
  - Удобный интерфейс подачи обращений
  - Автоматические уведомления о статусе работ
  - Экономия времени на звонках в диспетчерские

- **Для диспетчеров**
  - Снижение нагрузки на телефонные линии
  - Автоматизация рутинных задач
  - Удобная система управления обращениями
  - Аналитика и статистика обращений

- **Для РСО**
  - Оптимизация затрат
  - Улучшение репутации
  - Повышение эффективности работы
  - Аналитика для принятия решений

### 🛠 Технологии

- React Native
- TypeScript
- Node.js
- PostgreSQL
- Python (модуль ИИ)
- Firebase Cloud Messaging

### 📱 Поддерживаемые платформы

- iOS 14.0+
- Android 8.0+

### 📊 Результаты внедрения

- Снижение нагрузки на диспетчеров на 40-50%
- Сокращение времени обработки обращений до 2-3 минут
- Повышение удовлетворенности жителей на 20-30%
- Экономия ресурсов РСО до 60%
